# Taskfile Workflow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Task v3 workflow for installing, starting, testing, building, and exporting the Slidev presentation as a PDF.

**Architecture:** `Taskfile.yml` remains a thin command layer over the project’s existing pnpm scripts and Node test command. Slidev’s native exporter uses an exact `playwright-chromium` dev dependency, while documentation keeps direct pnpm usage available.

**Tech Stack:** Task v3, Node.js 22.12.0, pnpm, Slidev 53, Playwright Chromium, Node test runner

**Spec:** `docs/superpowers/specs/2026-11-18-taskfile-design.md`

## Global Constraints

- Use Task v3 syntax.
- Keep the existing `build`, `dev`, and `export` package scripts as the underlying Slidev commands.
- Install `playwright-chromium` as an exact dev dependency.
- Export PDF to `battle-tested-wagtail.pdf`.
- Keep `battle-tested-wagtail.pdf` untracked.
- Do not add DeckTape.

## Review Focus

- A machine without Task should still be able to use every documented direct pnpm command.
- A fresh frozen pnpm install must approve and install `playwright-chromium` without an ignored-build failure.
- `task` must list commands rather than recursively invoking the default task.
- Task definitions must pass CLI arguments to pnpm correctly, especially the PDF output argument after `--`.
- A generated `battle-tested-wagtail.pdf` must not appear in `git status`.

### Task 1: Add and verify the presentation workflow

**Files:**
- Create: `Taskfile.yml`
- Create: `tests/taskfile.test.mjs`
- Modify: `package.json`
- Modify: `pnpm-lock.yaml`
- Modify: `.gitignore`
- Modify: `README.md`

**Interfaces:**
- Consumes: package scripts `dev`, `build`, and `export`; `pnpm-workspace.yaml` approval for `playwright-chromium`; Node test files matching `tests/*.test.mjs`
- Produces: Task commands `install`, `start`, `test`, `build`, and `pdf`; PDF artifact `battle-tested-wagtail.pdf`

- [ ] **Step 1: Write the failing Taskfile contract test**

Create `tests/taskfile.test.mjs` using `node:test`, `node:assert/strict`, and `readFile`. Assert that:

- `Taskfile.yml` uses version `'3'` and defines `default`, `install`, `start`, `test`, `build`, and `pdf`.
- The commands are exactly `task --list`, `pnpm install --frozen-lockfile`, `pnpm run dev`, `node --test tests/*.test.mjs`, `pnpm run build`, and `pnpm run export -- --output battle-tested-wagtail.pdf`.
- `package.json` has an exact, unprefixed semver value for `devDependencies.playwright-chromium`.
- `pnpm-workspace.yaml` approves `playwright-chromium` under `allowBuilds`.
- `.gitignore` contains `/battle-tested-wagtail.pdf`.
- `README.md` documents `task start` and `task pdf` while retaining `pnpm run dev` and `pnpm run export`.

- [ ] **Step 2: Run the focused test and verify it fails**

Run: `node --test tests/taskfile.test.mjs`

Expected: FAIL because `Taskfile.yml` and the exact Playwright dependency do not exist yet.

- [ ] **Step 3: Add the exact native-export dependency**

Run: `pnpm add --save-dev --save-exact playwright-chromium`

Expected: `package.json` gains `devDependencies.playwright-chromium` with an unprefixed version and `pnpm-lock.yaml` records the package and Chromium download dependency.

- [ ] **Step 4: Implement the Taskfile and generated-file ignore rule**

Create `Taskfile.yml` with descriptive Task v3 entries for `default`, `install`, `start`, `test`, `build`, and `pdf`, using the exact commands asserted in Step 1. Add `/battle-tested-wagtail.pdf` to `.gitignore` near the existing Slidev export patterns.

- [ ] **Step 5: Document Task as an optional convenience layer**

Update `README.md` to state that Task is optional, link to <https://taskfile.dev/installation/>, show `task install`, `task start`, `task test`, `task build`, and `task pdf`, and retain the corresponding direct pnpm/Node commands. State that PDF export writes `battle-tested-wagtail.pdf`.

- [ ] **Step 6: Run the focused contract and Task parsing checks**

Run:

```sh
node --test tests/taskfile.test.mjs
task --list
task --dry install
task --dry start
task --dry test
task --dry build
task --dry pdf
```

Expected: the test passes; Task lists all five named workflow tasks; each dry run prints its exact delegated command without executing it.

- [ ] **Step 7: Run project verification**

Run:

```sh
pnpm install --frozen-lockfile
node --test tests/*.test.mjs
pnpm run build
task pdf
test -s battle-tested-wagtail.pdf
git check-ignore -q battle-tested-wagtail.pdf
git status --short
```

Expected: install succeeds without an ignored-build error; all tests pass; the Slidev build succeeds; the PDF exists and is ignored; `git status --short` contains only the intended source, lockfile, documentation, and test changes.
